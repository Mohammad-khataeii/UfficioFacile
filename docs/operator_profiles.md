# Operator Profiles

`operatorProfiles` in `assets/catalog/ufficio_catalog.v1.json` are the planned source for future operator dropdown and operator-specific support UI.

Store addresses should not be copied into the catalog. The app should open official store locator links because operator stores and opening hours change often.

If curated Torino store entries are added later, each one should include a `lastVerifiedAt` value so the data can be maintained responsibly.
